A one-sentence satirical roast of lawmakers who would regulate AI but cannot convert a file to PDF.

## Run it

```sh
python3 main.py
```

It writes the sentence to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` if that variable is unset), validates it is a single line of 1–320 characters, reads it back to verify, and exits 0.
